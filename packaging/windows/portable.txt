XueLuoPDF portable mode

While this file sits next to xueluopdf.exe, XueLuoPDF keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the XueLuoPDFData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move XueLuoPDF with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\XueLuoPDF and
%LOCALAPPDATA%\XueLuoPDF) instead. If XueLuoPDFData can't be written (for example on a read-only
drive), XueLuoPDF says so and uses the per-user folders instead.
